# 動画制作

「動画を作りたい」と言われたら、**他の作業より先に** `promo/00_START_HERE.md` を読む。毎回。

1. `promo/00_START_HERE.md` を読み、そこに書かれた順にファイルを読む
2. 作業の前に、Jakeに短く確認する（ハウツーかMVか／どのアプリか／主人公／MVなら曲）
3. 絵コンテ（画像）→ カメラワーク確認 → クレジット見積もり → 承認 → 動画化、の順を守る
4. Jakeが「始めて」と言うまで、生成やファイルの変更はしない
5. 新しく分かったことは `promo/` に追記してコミットする（PRは頼まれたときだけ）
