## 2. 動画の型（スクアドで効いた型を主催者版に変える）
**「人が出てくる」「悩む → 使う → 表情が変わる」**。文字とアプリ画面だけの動画はNG。
- 0–3秒（フック）: 困り顔の主催者。例「受付で行列…名簿の集計が終わらない」
- 3–7秒: 悩みの具体（紙の名簿、Excel、マッチング集計、個人情報の管理）
- 7–12秒: SCADコネクトの**実画面録画を3〜4秒**（受付QR→投票→成立ペア表示）
- 12–16秒: 笑顔で「もう終わった」。表情の落差を見せる
- 16–20秒: エンドカード（アプリ名／一言／QR）
- 長さは20秒以内（目安は14〜15秒。速くテンポよく）。縦（9:16）
- 案: A「受付も集計も、スマホ1つで」／B「連絡先を預からない街コン運営」／C「終了後にデータが自動で消える安心」

## 4. 制作の進め方（この順番）
1. 企画を2〜3案出す → Jakeが選ぶ
2. 主人公を1人決める（**毎回同じ顔**）。基準画像を1枚作り、全カットをそれで揃える
   - 画像: Higgsfield `soul_2`（基準）→ `gpt_image_2_5` に基準画像を参照させて各カット（高画質 `quality: high`）
   - 写真コンテ6カットを作って、Jakeに確認してもらう（企画書がわり）
3. 人物カットだけ動画化: Higgsfield `kling3_0`、`mode: pro`、5秒、`sound: off`、`start_image` に写真コンテの画像
4. 声: `qwen_audio_tts`（演技指示つき）。スクアドは女性の声（Hana）。**主催者版は声の人物に合わせて新しく選ぶ**（`list_voices`）。サンプルを2〜3種作ってJakeに聞き比べてもらう
5. 組み立て: Higgsfieldの `sandbox_exec`（ffmpeg + PIL）。スクリプトは `promo/sukuado/build_v3.py` を参考に
6. 完成後、投稿文（TikTok／YouTubeショート）と表紙を作る

## 5. 品質ルール（詳細は PROMPT_RULES.md）
- **AIっぽさを抜く**: 強いレタッチ・肌補正なし。スマホで撮った生活感のあるスナップの質感
- **スマホ／PCの向き**: 画面は使っている本人の方を向く。**カメラ側から見える裏面に画面が出ている間違い**を必ずチェック（ノートPCも、画面が本人側を向いているか確認）
- **明るさ**: 生成時に「明るく」と入れ、仕上げで全カット +約7%（`eq=brightness=0.03:gamma=1.07`）
- **演技は控えめ**: 目を大きく見開く・大げさなリアクションは不自然になった。「静かにホッとする」くらいにする
- **最後の顔は笑顔で終わる**: ラストが疲れた表情・上を見上げる動きだと印象が悪い。必要なら笑顔の部分だけスロー（0.5倍）で伸ばす
- **文字を顔にかけない**: 字幕・表紙の文字は顔を避ける（上下の空きに置く）。確認は画像で
- 注意書き: 「※演出・AI生成映像です」「※AIの回答は一例です」ではなく、**主催者版は「※画面はデモデータです」**にする
- 投稿時: TikTok「AI生成コンテンツ」ON（投稿画面の「詳細オプション」内）、YouTube「改変されたコンテンツ」=はい、カテゴリ「ハウツーとスタイル」、「子ども向けではない」

## 6. 音の作り方
- 声＋効果音を動画に入れて書き出す。**BGMはJakeが投稿時に入れる**（入れない）
- 声は短い「つぶやき」「一言」にする（ナレーション調はAIっぽくなる。前回、ElevenLabsの説明調ナレーションは不採用）
- 数字や固有名詞が読めないときは、ひらがなにする。「スクアド」は文字起こしで「スクワード」になることがあったので、発音は聞いて確認
- 声同士を重ねない。速度は最大1.2倍。効果音は音量55%で敷く（合成音を ffmpeg/Python で生成）
- 書き出し後、自動の文字起こし（`faster_whisper`）で、セリフが聞き取れるか確認

## 7. エンドカードとQR
- 内容: アプリ名／一言／「プロフのリンクから」／QR＋URL。QRは右下だと顔にかかるので位置に注意（TikTokは右下にボタンが重なる）
- QRは Python `qrcode` で作り、**書き出した動画の画面から `cv2.QRCodeDetector` で読み取って、URLが一致することを確認**する

## 8. 環境の制約（クラウド版Claude Codeの場合）
- この環境から Higgsfield の生成物・外部サイトを**直接ダウンロードできない**（403）。動画の確認と組み立ては、Higgsfieldの `sandbox_exec` の中で行う
- Jakeのファイルを受け取る: `media_upload_widget`（`max_files` と `min_files` を実際の本数に合わせる。合わないとContinueが押せない）。チャット添付はHiggsfieldに渡せない
- 出力ファイルの渡し方: 先に `media_upload` で URL を取得 → 同じ `sandbox_exec` の中で `curl -X PUT` でアップロード → `media_confirm`。sandboxは10秒ほどで消えるので、**素材のダウンロードから書き出しまでを1回の呼び出し（またはバックグラウンド実行）で完結**させる。長い処理は `background: true`
- Googleドライブ連携では**数MBの動画はアップロードできない**。動画はJakeに保存してもらい、ドライブにはリンクをまとめたメモを置く
- 画像のチェックは `sandbox_exec` の `image_paths`（合計512KB以内）で行う
