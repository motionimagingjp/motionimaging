# 引き継ぎ書：SCADビューティー 宣伝ショート動画（新しいチャット用）

このファイルを新しいチャットに渡して「これを読んで進めて」と伝える。
同じフォルダの `PROMPT_RULES.md`（生成ルール）も必ず読むこと。

## 0. 依頼者（Jake）の好み
- 説明は簡潔に、分かりやすく。**確認が必要なことは作業の前に聞く**
- コードは書かない。実装・生成はAIに任せる
- 生成でクレジットを使う前に、**残高と見積もりを見せてOKをもらう**（画像は1枚約1、Kling動画は5秒で約9クレジット）

## 1. 一番大事な方針（スクアド制作で決まったこと）
- **文字とアプリ画面だけの動画はNG**（つまらない、広告に見えて飛ばされる）
- **人が出てくる動画にする**: 目安は人7割、アプリ画面2割、ロゴやリンク1割
- 流れは「**悩む → アプリを使う → 表情が変わってスッキリ**」。気持ちの落差を見せる
- アプリ画面は本物の画面録画を**3〜4秒だけ**入れる（本物であることが信頼になる）
- 動画は15〜20秒、縦（9:16）。最初の2秒に「表情か、意外な絵」を入れる

## 2. 進め方（この順番で）
1. **企画をいくつか出す**（プロのTikTok企画者・SNS広告マーケターの目線で）。Jakeに選んでもらう
2. **写真コンテを6カット作る**（企画書がわり）。まず主人公の基準画像を1枚作り、全カットをその顔に揃える
3. Jakeが写真をチェックし、OKが出たら**人物のカットだけ動画にする**（Kling 3.0の高画質モード、5秒、音なし）
4. 画面録画・声・BGM・字幕・エンドカードを入れて組み立てる（ffmpeg + PIL。スクアドの `build_tiktok.py` が参考になる）

## 3. 画像・動画の品質ルール（詳しくは PROMPT_RULES.md）
- **AIっぽさを抜く**: 強いレタッチや肌補正をしない。毛穴やおくれ毛を残し、生活感のある部屋、スマホで撮ったスナップのような質感にする
- **スマホの向き**: 画面は持っている本人の方を向いている。カメラ側から見える裏面はレンズのみ（裏にも画面がある、というAIによくある間違いを必ずチェック）
- **明るさ**: プロンプトに「明るく」と入れ、仕上げで全カットに+約7%（5〜10%）
- **使えない素材**: 本物のLINE画面、第三者の情報、CapCut等の透かしが入った素材
- 投稿時は「AI生成」ラベルをONにし、「※演出です」「※AI診断は一例です」と表記する

## 4. SCADビューティーについて（分かっていること）
- URL: https://scad-beauty.vercel.app/
- 内容: AIパーソナルカラー診断（別名「イロナビ」）。ヘア・ファッション・レストランのAIアドバイス
- **新しいチャットで最初にJakeに確認すること**:
  - 一番伝えたい強みは何か（例:「自撮り1枚で似合う色が分かる」）
  - 想定している利用者（性別・年齢）
  - 画面録画はあるか（なければ、録画してほしい操作を具体的に指示する）

## 5. 企画のたたき台（新しいチャットで深める）
- **A「似合わない服、もう買わない」**: 鏡の前で服に迷う → 自撮りで診断 → 似合う色が分かる → その色の服で街に出て笑顔
- **B「美容院で毎回うまく伝えられない」**: 美容院の前で不安な顔 → アプリでヘアの提案を見る → 仕上がりに満足して笑顔
- **C「ビフォーアフター」**: くすんで見える服の色 → 診断で選んだ色 → 顔色が明るく見える、という対比（TikTokで強い型）
