# 宣伝動画・MV 制作ルール：まとめ（ハウツーとMVの違い）

同じフォルダの `HANDOVER_VIDEO_PRODUCTION.md` と `PARTYCONNECT_VIDEO_RULES.md`（2026-10-06〜07、Jakeの指示）を要約したもの。
食い違う場合は、そちらを優先する。入口は `00_START_HERE.md`。

**最初に必ず、Jakeに「ハウツー・宣伝か、MVか」を確認する（確認は作業の前に）。**

## 1. 2つの違い

| 項目 | ハウツー・宣伝・紹介（SCADコネクト等） | MV（ミュージックビデオ） |
|---|---|---|
| スピード | 速くてよい。素材は1.4〜1.5倍速 | **等倍のまま。速めない** |
| 長さ | **20秒以内**（目安は14〜15秒。長くしすぎず、テンポよく） | **ショート版も20秒以内**。曲の20秒分（サビなど）を使う |
| カット | 人物カットは1.5〜2.5秒で切り替え | 5秒のカットを曲のテンポに合わせて並べる（20秒なら4カット前後） |
| 曲 | 基本は投稿時にJakeが入れる。入れるなら声より小さく | Jake自作の曲が主役。**曲を先に確認**して、映像を曲に合わせる |
| クレジット | 1本 約8.75（kling3_0 pro 5秒）×カット数 | カット数が多くなる。**必ず先に見積もりを出す** |
| 視聴者 | 街コン主催者などの見込み客 | 音楽ファン（YouTubeの再生リストも分ける） |

MVで未確認（作る前にJakeに確認）：声・字幕・QRを入れるか／曲のどの20秒を使うか（サビなど）と雰囲気／投稿先

保存済みの曲（Jake自作・5曲）：TWO / Cold Moon、4AM、1AM、Dice、Lost in the Code
（長さ・雰囲気は未確認。使う前に確認）

## 2. 両方に共通するルール

1. 順番は変えない：絵コンテ（画像）→ カメラワーク確認 → クレジット見積もり → OK → 動画化 → 組み立て → 自動チェック
2. 絵コンテで流れが決まるまで動画は作らない（画像 約1クレジット、動画 約8.75クレジット）
3. 登場人物はHiggsfieldのエレメント（プロンプトに `<<<ID>>>`。`@名前` は使えない）
   - Saki `6ded8d7a-eb58-4bb7-8395-9b22c36984ef`
   - Rio `601905da-b348-4868-a079-a0fc61511b1e`
   - 男性ジョンジンは未登録（元画像を参照画像で渡す）
   - 1本の中では主人公を1人に固定。別人を混ぜない
4. カメラワーク：カットごとに動きを変える（押し込み／右→左／左→右／引き／見上げズーム）。隣のカットで同じ動きを続けない。
   ドローン風の降下は弱かった。`start_image`＋`end_image` で引き→寄りが確実に出る
5. 絵コンテ：`gpt_image_2`、quality high、9:16、黒帯なし、生活感のあるスナップ質感、肌補正なし。
   小物は全カット統一。スマホは白一色で、画面は本人側・カメラ側に白い背面とレンズ。
   看板・紙に読める文字を入れない。人物は大きく（頭と肩で画面の約45%）。文字は顔にかけない。演技は控えめ。ラストは笑顔
6. 動画化：`kling3_0`、mode pro、5秒、sound off。プリセットを提案されたら `declined_preset_id` で同じ内容を再送
7. 明るさ：人物カットは `eq=brightness=0.03:gamma=1.07`
8. 画面録画：時刻・電波・録画マーク・操作バーを切って全画面。ダミーデータだけ。下に「※画面はデモデータです」
9. 書き出し後の自動チェック：文字起こしでセリフ、`cv2.QRCodeDetector` でQR、代表フレームで文字かぶり・黒帯・赤ボタン
10. 組み立ては `sandbox_exec` で、ダウンロード〜書き出しを1スクリプトにして `background: true`。
    完成品は `media_upload` → PUT → `media_confirm`

## 3. ハウツー・宣伝だけのルール

- 型：悩む → 使う → 表情が変わる。機能は主要なものを全部見せる（SCADコネクトは「受付（チェックイン）」と「マッチ」）
- エンドカードにQR必須（YouTube用とTikTok用でUTMを分ける）。表紙も作る
- 声：`qwen_audio_tts`（Hana）。言い方の指示は短く（長いと指示文まで読み上げる）
- 機能の主張は `partyconnect/README.md` の範囲だけ。表示名は「SCADコネクト」

## 4. MVだけのルール

- ショート版は20秒以内。曲の20秒分を切り出して使う（どの部分かは先にJakeに確認）
- 映像を曲に合わせる。速めない
- カットが増えるので、見積もりを先に出す
- カメラワークとエフェクトのルールは、ハウツーと同じく守る

## 5. Jakeの好み

説明は簡潔に。確認は作業の前に。手作業は避け、自動化を優先。
自分でも編集して仕上げるので、短く切りやすい良い素材を渡す。
