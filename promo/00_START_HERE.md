# 動画制作の入口（まずここを読む）

「動画を作りたい」「宣伝動画」「ショート」「MV」「TikTok／YouTubeショート」などと言われたら、
**他の作業より先に、このファイルを読んで、下の順に進める。** 毎回。

## 1. 読む順番

| 順 | ファイル | 中身 |
|---|---|---|
| 1 | `VIDEO_RULES_MV_AND_HOWTO.md` | ハウツーとMVの違い（スピード・長さ・曲）、共通ルール。まずこれ |
| 2 | `HANDOVER_VIDEO_PRODUCTION.md` | 詳細な手順、登場人物のID、カメラワーク、つまずき集、素材ID |
| 3 | `PROMPT_RULES.md` | 画像・動画・声の品質ルール（AIっぽさ、スマホの向き、明るさ） |
| 4 | アプリ別（下） | 題材ごとの決まり |

アプリ別：
- SCADコネクト → `PARTYCONNECT_VIDEO_RULES.md`（正本）、`HANDOVER_PARTYCONNECT.md`（補足）
- SCADビューティー → `HANDOVER_BEAUTY.md`
- スクアド → `sukuado/build_v3.py`（組み立て例）。完成版などはGoogleドライブ「SCAD/スクアド_プロモ_20261005」

食い違うときは、**新しい日付・Jakeの最新の指示が優先**。上の表では、1と2が最新。

## 2. 作業の前に、Jakeに短く確認すること

1. **ハウツー・宣伝か、MVか**（ルールが違う）
2. どのアプリか（スクアド／SCADコネクト／SCADビューティー）
3. 主人公（Saki／Rio／男性ジョンジン）と場面
4. MVなら：どの曲の、どの20秒か

## 3. 決まっていること（2026-10-07 時点）

- ショートは **ハウツーもMVも20秒以内**（ハウツーは目安14〜15秒）
- ハウツーは素材1.4〜1.5倍速、MVは等倍
- 順番：絵コンテ（画像）→ カメラワーク確認 → クレジット見積もり → Jakeの承認 → 動画化 → 組み立て → 自動チェック
- SCADコネクトの主人公は **Saki**（エレメントID `6ded8d7a-eb58-4bb7-8395-9b22c36984ef`）
- 自分の判断でクレジットを使わない。Jakeが「始めて」と言うまで、生成やファイルの変更はしない
- Jakeの好み：説明は簡潔に。確認は作業の前に。手作業は避けて自動化

## 4. 環境の注意（クラウドのClaude Codeの場合）

- Higgsfieldの生成物は、この環境から直接ダウンロードできない。確認と組み立ては `sandbox_exec` の中で行う
- Googleドライブ連携では、数MBの動画はアップロードできない。動画はJakeに保存してもらい、ドライブにはリンクのメモを置く
- Higgsfieldのツールが使えない環境では、企画とルールの確認までにする

## 5. 新しく分かったことの扱い

- `promo/` の該当ファイルに追記して、コミットする（PRは頼まれたときだけ）
- 入口（このファイル）は短く保つ。細かい内容は、各ファイルに書く
