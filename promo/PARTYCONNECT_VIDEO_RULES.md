# SCADコネクト 宣伝ショート動画 制作ルール

SCADコネクトの宣伝ショート動画(YouTubeショート / TikTok)を作るときの決まりごと。
2026-10-06 の制作(バージョンA・B)で決めたことをまとめている。次に作る人・AIはここから始める。

## 最重要ルール(必ず守る)

**動画は、絵コンテで流れが決まるまで作らない。**

1. 先に絵コンテ(画像)で、全カットの流れ・構図・小物・背景を決める
2. 依頼者(Jake)が絵コンテを見て「この流れでOK」と言ってから、初めて動画化する
3. 動画化の前に、クレジットの見積もり(1本あたり・合計)を見せてOKをもらう
4. 「まず1本だけ試す」場合も、絵コンテが決まっていることが前提
5. 絵コンテの修正は画像でやる(動画より安い。画像 約1クレジット、動画 約8.75クレジット)

理由: 動画は画像の約9倍のクレジットがかかり、作り直しの無駄が大きい。
絵コンテの段階で、顔・小物の色・スマホの向き・背景の人の年代・カメラ位置を直しておけば、動画の作り直しをほぼ防げる。

## 依頼者の好み

- 説明は簡潔に、分かりやすく。確認が必要なことは作業の前に聞く
- コードは書かない。生成・組み立てはAIに任せる(手作業は避ける)
- クレジットを使う前に見積もりを見せてOKをもらう
- 結果は「誰が見ても分かる短い文」で。表やリンクで見せる

## 視聴者と伝える内容

- 視聴者は「街コン・婚活パーティの主催者」(B2B)
- 伝える価値: 受付〜マッチング〜データ消去を1つで進行できる。連絡先を預からない
- 機能の主張は `partyconnect/README.md` と `docs/partyconnect_requirements.md` の範囲だけ。未確認の機能・数字・実績は言わない
- 表示名は「SCADコネクト」(旧PartyConnect)で統一
- 勝ちパターン: 「人が出る」+「悩みを問いかけるタイトル(〜?)」+「最初の1秒に大きな文字」。機能紹介型は伸びにくい

## 動画の型(15〜20秒、縦9:16)

「悩む → 使う → 表情が変わる」。文字とアプリ画面だけの動画はNG。

| カット | 内容 | セリフ |
|---|---|---|
| 1 | 受付の行列で困り顔。冒頭に「街コンの主催者さんへ／受付の集計、まだ手作業？」 | 「また集計…終わらない」 |
| 2 | 名簿とノートPCで悩む | なし |
| 3 | 白いスマホを操作する | 「これで、いけるかも」 |
| 4 | 画面録画(受付済み20名 → 成立ペア10組。ハートと「マッチ成立！」) | 効果音のみ |
| 5 | ホッとする | 「もう、終わった」 |
| 6 | 笑顔のOKサイン | なし |
| 終 | エンドカード(アプリ名／一言／「プロフのリンクから」／QR) | なし |

- バージョンA = 明るい会場、バージョンB = 夜のレストラン前の受付(場面と背景だけ違う。メッセージ・声・画面録画は共通)

## 絵コンテ(画像)のルール

- 画像モデル: `gpt_image_2`、`quality: high`、縦9:16。フル画面で、黒帯(レターボックス)を入れない
- 質感: 強いレタッチなし。スマホで撮った生活感のあるスナップ
- **ストラップは紺色の無地、カードは白い小さなカードに全カット統一**(色がバラバラだと変)
- **スマホは白一色**(本体・縁・ケース。黒を入れない)
- **スマホの向き**: 画面は本人の方を向き、カメラ側には白い背面とレンズが見える。画面がカメラ側に見える絵はNG
- **背景の人**: 30〜40代、黒髪・茶髪、白髪なし。会場は明るい
- **受付の配置**: スタッフは受付台の内側、お客様は台の手前に並んで受付に向かう(お客様がスタッフの後ろに並ぶのはNG)
- 看板・紙に読める文字を入れない(AIの文字は崩れる)。実在のロゴやQRを真似しない
- 人物は大きく。表情が見える大きさ(頭と肩で画面の高さの約45%)。文字は顔にかけず、上下の空きに置く
- 演技は控えめ(目を大きく見開かない、大げさなリアクションなし)。ラストは笑顔で終わる
- 体が揺れる動きは避ける。笑顔のカットは「肩から下を動かさず、片手のOKサインだけ」にする

## 動画化(絵コンテ確定後)

- `kling3_0`、`mode: pro`、5秒、`sound: off`、`start_image` に絵コンテの画像。約8.75クレジット/本
- 最初の絵と最後の絵を指定すると、カメラの動き(引きから寄る)を作れる(`start_image` + `end_image`)
- プロンプトが似たプリセット(IN THE DARK 等)を提案されても、使わずそのまま生成する(`declined_preset_id`)
- 動きの指定は短く具体的に。「手だけ動かす」「ため息」「静かにホッとする」

## 声(Higgsfield `qwen_audio_tts`、Hana)

- `voice_id`: `c25f78a0-714e-42af-8da3-a399cef94968`、`language: ja`
- **言い方の指示(instruction)は短く**。長いと指示文まで読み上げることがある。迷ったら指示なしで、セリフだけ生成する
- 声は短いつぶやき。ナレーション調にしない。声同士を重ねない
- 数字や固有名詞が読めないときは、ひらがなにする

## 保存済みのBGM(Jake作曲。Higgsfieldのメディアに保存済み)

BGMは動画本体には入れず、投稿時に入れるのが基本。動画に入れたい場合は、下の `media_id` を使って組み立てる(`sandbox_exec` で曲をダウンロードして、声・効果音と合成する)。
曲の長さ・雰囲気は未確認。使う前に、長さと音量(声より小さく)を確認すること。

| 曲名 | media_id |
|---|---|
| TWO | `e8b1922a-3653-40a5-92c3-c2e0591a5947` |
| Cold Moon, 4AM | `92e50aa5-6784-4aee-abca-f560203f4e0d` |
| 1AM | `7d5cbe27-c2dd-4f28-8297-1b6b62daea2c` |
| Dice(旧 Snow Falls) | `88c3b54d-3307-46c6-af84-ad2290dd5cf3` |
| Lost in the Code | `28549caa-b858-4c5f-975e-254882fe1964` |

- 曲を動画に重ねるときは、声の場面(約0〜4秒、5〜9秒、13〜16秒)は曲をさらに小さくする
- 曲のダウンロードURLは、メディア一覧(`show_medias`)か、`media_id` から取得する
- ユーザーの手元のファイルをHiggsfieldに入れるときは、`media_upload_widget` で1ファイルずつ(複数選択は使えない)

## 組み立て(Higgsfieldの `sandbox_exec`、ffmpeg)

- この環境(クラウド版Claude Code)から、Higgsfieldの生成物は直接ダウンロードできない(403)。組み立てはsandbox内で行う
- ローカルの素材は、`media_upload` でURLを取り、`curl -X PUT -H "Content-Type: ..." -H "If-None-Match: *"` でアップロード → `media_confirm`
  - 環境のネットワーク設定で `upload.higgsfield.ai` を許可しておく必要がある
- sandboxは約10秒で消える。ダウンロードから書き出しまでを1つのスクリプトにして `background: true` で実行する
- 完成動画のアップロード先は、書き出し**前**に `media_upload` で取っておき、同じスクリプトの最後で PUT する
- 全カット明るさ +約7%: `eq=brightness=0.03:gamma=1.07`(人物カットのみ)
- 効果音は音量を控えめに。BGMは入れない(Jakeが投稿時に入れる)
- 画面録画: 時刻・電波・録画マーク・ブラウザの操作バーを切り取り、**余白なしで画面いっぱい**(1080x1920)にする。実在のURL・QR・赤い「データを消去」ボタンは映さない。下に「※画面はデモデータです」
- 成立ペアの場面: ハートが浮かぶ演出と「マッチ成立！」の文字

## 書き出し後の確認(自動)

- 文字起こし(faster_whisper)で、セリフが聞き取れるか
- エンドカードのQRを、書き出した動画の画面から `cv2.QRCodeDetector` で読み取り、URLと一致するか
- 代表フレームの一覧を作り、文字が顔にかかっていないか、黒帯・余白がないか、赤いボタンが映っていないかを画像で見る

## エンドカード・QR・リンク

- 内容: SCADコネクト／受付も集計も、スマホ1つで／プロフのリンクから／QR+URL
- QRのURL(YouTube用): `https://scad-partyconnect.vercel.app/?utm_source=youtube&utm_medium=referral&utm_campaign=top`
- QRは中央〜下寄り。右下はTikTokのボタンと重なる
- ショートの説明欄・コメントのリンクはタップできない可能性が高い。動画内のQRとチャンネルのプロフィール欄のリンクが頼り

## 投稿設定

- YouTube: 「改変されたコンテンツ」=はい、「子ども向けではない」、カテゴリ=ハウツーとスタイル
- TikTok: 「AI生成コンテンツ」ON(投稿画面の「詳細オプション」内)
- 注意書きは「※画面はデモデータです」。説明欄に「※演出・AI生成映像を含みます。」も入れる
- 表紙(サムネイル)は、大きな文字入りの最初の場面。文字は顔を避ける
- 投稿後に動画ごとの「視聴者維持率」「視聴者層」を確認して次に反映
