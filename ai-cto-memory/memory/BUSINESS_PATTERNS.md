## インフラ・コスト管理

- **Vercel Hobbyプランの制約は変遷する。前提を都度疑う。** cron本数上限は2026年1月に撤廃・全プラン100本/プロジェクトに統一された。過去の制約を前提にした設計（内部fetchで1本のcronに集約する等）は、制約解消後は不要な複雑さの温床になる。
  - 根拠: Migoron
- **X APIのコスト構造**：テキストのみ投稿$0.015/件、URL付き投稿$0.20/件（約13倍）。CTA（誘導リンク）は全投稿にではなく曜日・頻度を絞って付与するのがコスト最適化の観点からも合理的。
  - 根拠: Migoron, スクアードX, jake_images
- **複数SNSアカウントを運用する場合、プリペイド残高・Developer App・環境変数をアカウントごとに分離管理する。** 共有するとどのアカウントがいくら消費したか追えなくなる。
  - 根拠: Migoron/スクアードX/jake_images共存リポジトリ

## 外部サービスの期限・仕様管理

- **Instagram/Threadsの長期アクセストークンは60日で失効する。** カレンダーでの期限管理が必須。将来的には自動更新（`refresh_access_token`）の実装が望ましい。
  - 根拠: Migoron, jake_images
- **無料プランのログ保持期間はほぼゼロと想定する。** 障害調査はブラウザDevToolsのNetworkタブや、アプリ自身が返すレポート（`?report=1`等）で行う方が確実。
  - 根拠: Migoron, SCAD Beauty

## 法務・コンプライアンス

- **「カウンセラー」「心理士・心理師」「セラピスト」は資格が必要な名称のため使用不可。** 「アドバイザー」「コーチ」等の表現に統一する。
  - 根拠: スクアード/DECODE（全バージョンで一貫）
- **画像関連の新機能は、実装前に著作権・肖像権・利用規約の3点を必ず確認する。** 検討を怠ると機能を作り込んだ後に全面廃止する手戻りが起きる。
  - 根拠: SCAD Beauty
- **特許出願前にアプリ・技術内容を公開すると新規性を喪失するリスクがある。** プロダクト公開のタイミングは特許出願の進捗と必ずすり合わせる。特許出願完了後に公開制約が解除され開発が加速した実例もあり、法的手続きの進捗確認は機能実装の順序決定に直結する。
  - 根拠: スクアード/DECODE, SCAD CHAT（特願2026-190649「コミュニケーション支援装置」の出願完了で開発加速）
- **恋愛・婚活支援AIは未成年をターゲット層に含めない。** 関係進展を後押しするAIの性質上、相手が誰であれ設計思想上のリスクが大きい。
  - 根拠: SCAD CHAT
- **Vercelの「ドメイン」は同一プロジェクトへの別名（エイリアス）に過ぎず、環境分離の手段にはならない。** 開発/本番環境を分けるにはGitブランチを使う必要がある。
  - 根拠: SCAD CHAT
- **マッチング機能（第三者の紹介）は結婚相手紹介サービス業の届出義務が、法律相談機能は弁護士法72条のリスクが、旅行の予約代行は旅行業登録がそれぞれ発生し得る。** 機能追加時に業種特有の規制を確認する。
  - 根拠: スクアード/DECODE
- **「LINE」はLINE社の商標のため、UI文言は「やり取りのスクリーンショット」等の一般的表現に置き換える。**
  - 根拠: スクアード/DECODE

## ドメイン知識

- **恋愛・婚活統計の主要な一次資料**：厚生労働省「人口動態統計」、司法統計、明治安田生命の年次婚活実態調査、こども家庭庁の調査。年次更新されるため四半期に一度は再確認が必要。
  - 根拠: スクアードX
- **婚活・恋愛マーケティングは「データ訴求（朝）」「共感訴求（夜）」で時間帯を分けると単調な広告に見えない。**
  - 根拠: スクアードX, Migoron（テーマの時間帯分離）
- **Instagram Graph API利用にはビジネス/クリエイターアカウントが必須（個人アカウントでは連携不可）。**
  - 根拠: Migoron, jake_images

## 開発体制・進め方

- **非エンジニア運用を前提にした復旧手順書化**：トークン更新・環境変数変更・Redeployの手順を明文化し、障害時に本人が対応できる状態を保つ。
  - 根拠: Migoron
- **複数チャットセッションで同一コードベースを並行編集する場合、デプロイ前に必ず「どのファイルが最新か」を確認する。**
  - 根拠: Migoron, SCAD Beauty
- **性質の異なる複数アプリ（婚活系／美容系）のCTA配分は「後発アプリほど露出を増やす」原則で定期的に見直す。** 実際に後発アプリの露出が先発アプリより少ない逆転現象が発生していた。
  - 根拠: jake_images
