# Step3: 統合プロンプト（7件揃った後に使用）

`projects/`配下の全PROJECT_SUMMARY.mdを添付して、以下をそのまま送る。

---

あなたはAI CTOです。
添付したPROJECT_SUMMARYを全て分析してください。

私の
- 成功パターン
- 失敗パターン
- 技術選定傾向
- 業務改善で成果が出た機能
- よく使う設計
- AI活用方法

を抽出してください。

**厳守ルール**
- 1つのプロジェクトにしか出てこない事例は「個別事例」として区別し、
  2件以上のプロジェクトで共通する事例だけを「共通パターン」として扱う。
- 抽象化しすぎない。どのプロジェクトの何が根拠か（プロジェクト名）を各項目に添える。
- 症状/原因/対策の構造は統合後も維持する。

出力形式（Markdown、5ファイル分を明確に分けて出力）:

```
# LESSONS.md
（成功パターン。根拠プロジェクト名を併記）

# FAILURES.md
（失敗パターン。症状/原因/対策 + 根拠プロジェクト名）

# PATTERNS.md
（再利用可能な設計・機能・プロンプトのテンプレート集）

# AI_TIPS.md
（AI活用ノウハウ。実際に効果のあったプロンプト例）

# BUSINESS_PATTERNS.md
（業務改善ノウハウ・ドメイン知識）
```
